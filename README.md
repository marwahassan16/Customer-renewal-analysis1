# Customer Renewal Analysis

A small portfolio project demonstrating a basic customer-renewal analysis using Python, pandas, and matplotlib.

## Questions
- What percentage of customers renewed?
- Does renewal differ by plan type?
- Are longer-tenure customers more likely to renew?
- Do support requests appear related to renewal in this small sample?

## How to run
1. Install Python 3 and the packages: `pandas`, `matplotlib`.
2. Run `python analysis.py` from this folder.

## Files
- `customer_renewals.csv`: illustrative sample dataset created for this portfolio example (not real client data).
- `analysis.py`: analysis and charts.

## Note
This is a demonstration project using a small synthetic dataset. It is not previous client work and should be described as a sample portfolio project.
